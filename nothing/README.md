# Nothing

An unlisted Easter egg at `/nothing/`. The index source contains its only discovery hint.

The button shows “Done.” for 1.4 seconds, then returns to “It’s working.” Repeated clicks restart that interval. There is no saved state or network operation.

Uses the shared Atomic Tools shell and follows the system light/dark preference. Open `index.html` directly for a local check; verify the button with both pointer and keyboard.
