# AI Coding Subscription Matrix

Compare AI coding subscriptions by price, quota, headroom, projected cost at usage, and representative quality signals.

## Development

Serve from the repository root:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080/ai-coding-subscriptions/

## Notes

- The page is static and makes no runtime API calls.
- Pricing, quota, and benchmark sources are linked from table cells.
- Representative quality signals are model-family benchmarks, not direct plan scores.
